# Архитектура

Три независимых вычислительных узла и клиентский киоск. Адреса конкретного развёртывания хранятся вне Git.

| Узел | ОС | Роль |
|---|---|---|
| LLM-1 | Debian 13 | Qwen3-VL 8B, Ollama, ComfyUI, GPU Manager |
| LLM-2 | ALT Server 11.1 | Qwen 27B, llama.cpp, Open WebUI |
| VISION | ALT Server 11.1 (план) | Приём и анализ JPEG/PNG, PostgreSQL |
| Киоск | Репка Pi 4 | Камера, интерфейс, клиент API |

LLM-2: Core i5-13400F, 32 ГБ DDR5, RTX 4060 8 ГБ, отдельный SSD. Модель Q4_K_M (~18,07 ГиБ), mmproj на CPU, 18 слоёв на GPU, 10 потоков, контекст 8192, один слот. Измерено 4,07–4,98 токена/с против 3,43 на CPU; запросы разные, не строгий benchmark. VRAM 6184 МиБ в покое. 

Open WebUI слушает TCP 3000; llama.cpp — только loopback 8082. VISION использует HTTPS 8443. GPU Manager первого узла управляет очередью и переключением моделей; не переносить его автоматически на второй узел. Текущий код менеджера не включён в репозиторий.

Киоск отправляет отдельные кадры по явному действию, а не непрерывный скрытый поток. Связь фото с подтверждённым ID студента осуществляется через университетскую учётную запись или QR-код. Нейросетевой анализ изображения не является подтверждением личности.
